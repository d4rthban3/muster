Install Muster

A crew of Claude Code chats: a manager you talk to, builders, a designer and an inspector. Set up from one page.

In the Claude desktop app

Press the button. A new Claude Code chat opens with the install message already written, and setup runs in that same chat.

Open in Claude Code
  1. Press Enter to send the message.
  2. When Claude asks, click Allow.
  3. The setup page opens by itself.

Nothing happens? You may not have the desktop app yet; use the commands below, or get the app.

In a terminal

Run these two commands, then open Claude and type the last line.

claude plugin marketplace add d4rthban3/muster
claude plugin install muster@muster-kit --scope user
/muster:setup

Then open Claude and type /muster:setup.

No Claude yet?

Muster runs inside Claude Code. Get the Claude app first, then come back here.
