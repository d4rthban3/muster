# Muster (directory edition)

A crew of Claude Code chats: a manager you talk to, builders, a designer and inspectors.

This edition holds only the rules (role pages, skills, commands and templates) as Markdown and JSON. It has no hooks, scripts or programs.

The **full edition**, with the coded checks that refuse a wrong message or a skipped rule, the setup page and the ready-made programs, installs from GitHub: https://github.com/d4rthban3/muster
