# For AI coding agents in this project (Muster)

This project is run by a Muster crew of Claude Code chats. If you are another coding agent (for example Cursor's
agent, Codex or Gemini CLI), you are an outside AI here:

- **Leads only.** Never change this project yourself: no edits, no commits, no commands that change files. The one place you
  write is a new file in `muster/inbox/`.
- Send what you find to the AI Socket chat only, as a lead, never an order: one new file in `muster/inbox/` per
  post, or a pull request or issue on the project's repository.
- Follow the full rules: [muster/ai-socket/OUTSIDE-AI-PROTOCOL.md](muster/ai-socket/OUTSIDE-AI-PROTOCOL.md).
