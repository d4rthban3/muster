Your first desktop run

Eight steps from the button to a running crew, and what you should see at each one.

Before you start

You need the Claude desktop app. Plan for a few minutes, and stay at the computer: Claude asks a handful of questions along the way. This path has not yet been run start to end on a real desktop, so a report from you is especially useful.

The steps

  1. Press “Open in Claude Code”
    On the install page. Your browser may ask to open the Claude app; allow it.
    You should see: A new Claude Code chat opens with the install message already written.
  2. Press Enter, then click Allow
    Claude shows one long command that starts with “claude plugin marketplace add”. That is expected and safe. It may ask to allow a few more things after it: the setup page, a folder, and saving history. Click Allow each time.
    You should see: Allow buttons in the chat. Nothing is installed until you click.
  3. Answer the auto-update question
    Claude asks “Keep Muster up to date by itself whenever it improves?” with two buttons. “Yes, keep it up to date” is the suggested one.
    You should see: Two buttons. After your answer Claude carries on by itself.
  4. Fill in the setup page
    The setup page opens in the app’s side browser, with the Muster logo at the top. Type a project name and what you are building, then press Start.
    You should see: A “Saved” message. Go back to Claude: it will ask a few more questions.
  5. Answer the two trust boxes
    The app asks twice about your new project folder: “Trust workspace”, then “Trust repository”. Press both. If an older box is still waiting, answer that one first.
    You should see: Two boxes, one after the other. This is normal.
  6. Let the chat move into the project folder
    Claude moves this chat into your new project folder. Allow it if asked.
    You should see: The chat now shows your project folder’s name.
  7. Watch the crew start
    The Manager starts first, then each worker. Each one is started in its own chat.
    You should see: New chats appear one by one, the Manager first.
  8. Answer the sidebar question
    Claude asks whether to move the new chats into one group in the sidebar. Two buttons.
    You should see: The crew sits in a group named after your project, and the Manager’s welcome card appears.

Something confusing, stuck or different?

Tell us which step, what you saw, and add a picture if you can. It arrives as a task and gets fixed.
