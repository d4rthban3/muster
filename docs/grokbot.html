Muster in Grok Bot

How to run the crew in Grok Bot. untested

Read this first

Untested. Nobody has run a new Muster crew in Grok Bot from these steps. They come from a written plan built on an earlier hand-made setup, and one step (a single link that brings the helper bots and routines with it) is not known to work. For what works where, see the compatibility table. Plain Grok, without Grok Bot's tools, can only use Muster Lite.

Set up

  1. Open a shareable Muster bot template (the Manager with its setup prompt). There is no official one yet; until there is, ask the Manager bot to set up from the Muster repository.
  2. Add Muster's skills to your skills library once. Every bot of yours then shares them, so a new Muster version is one update, not a copy per project.
  3. The Manager asks the setup questions with buttons: project name, what you are building, and which crew.
  4. It makes a helper bot for each role that needs memory (Builders and the Designer). Checks that should start fresh, like the Inspector, run as background jobs in the Manager's chat instead.
  5. It writes only your project's records (owner's list, decisions, board, crew) in a Muster folder kept out of your project's history.
  6. Optional: a routine that posts the board digest, and one that checks for a new Muster version.

Which role runs where

RoleRuns asWhy
ManagerYour own chatYou talk only to it.
Builder, DesignerHelper botThey build over many turns and gain from remembering the project.
Inspector, Design InspectorBackground jobFresh eyes on every READY, and no extra round trip.
Board digest, leak scanBackground job, or a routineOne-shot jobs; no need to run every turn.

What is different from Claude Code

  • The rules here are not enforced by code. Muster’s coded checks run only in Claude Code; here the Manager runs scripts/check-edition.py over the board and tells you what it finds.
  • A helper bot's reply is its six-line report; there is no separate end-of-turn line.
  • Messages are held by default. Wake a bot only for an order, a READY, a PASS, a FAIL, an OWNER CALL, STUCK or NEED, and put anything it must obey inside its next order.
  • Long chats are summarized by the app, so there are no renewal handover files. Archiving means hiding the chat from the sidebar.
  • Choices use the app's question buttons.

Muster is a community plugin. It is not made or supported by Anthropic.
