Muster in Cursor

How to run the full crew — manager, builder, designer, inspector — in Cursor. untested

Read this first

Untested. Nobody has run Muster inside Cursor yet. These steps come from Cursor’s documentation, not a real run, so a step may not look exactly as described. If it doesn’t, tell the crew which step. For what works where, see the compatibility table.

Cursor agents cannot message each other. The crew passes work on a shared board, and you open a chat and type anything when the Manager says that chat has something waiting.

Set up (no terminal needed)

  1. Open your project’s folder in Cursor and start a new Agent chat there.
  2. Paste this one message and press Enter. When Cursor asks to run a command, click Run or Allow. 
    Set up Muster for this project. First ask me for the project's name and one sentence on what I am building. Then get Muster (`git clone https://github.com/d4rthban3/muster` into a folder next to this project, unless it is already there), run its `cursor/setup.py` on this project's folder with that name and sentence, and show me the folders and starting-note files it prints.
    You should see: Cursor asks for the project’s name and what you are building, then lists a folder and a starting-note file for each agent.
  3. For each agent it lists, Manager first: open that agent’s folder in Cursor, start a new Agent chat, open the starting-note file it names, and paste its whole contents as your first message.
  4. Talk only to the Manager. When it says “X is waiting for you: type in <chat>”, open that chat and type anything.
  5. To see what is waiting at any time, look at the top line of muster/BOARD.md (“Waiting on:”).

What is different from Claude Code

  • No chat-to-chat messages and no notifications: the board carries every handoff, and you wake a chat by typing in it.
  • The rules are Cursor rules. They are advice the agent reads; only one check, the Manager’s stop check, is enforced.
  • Not included: one-command shipping, the usage meter, and the renewal-after-summary step.
  • Cursor may tidy away the project copies it did not make. If a builder’s folder vanishes, tell the Manager.

Something went wrong?

Use Report a snag and say which step. The full technical notes are in the Cursor folder.
